# Источник дополнительных фотографий

High-Resolution Dataset of Common Bean Leaf Diseases in Bangladesh, версия 1.

Авторы: Jahanur Biswas, Md Mahamudul Hasan, Md Shakib Hossain.

[Mendeley Data, DOI 10.17632/89c9r5m2gx.1](https://data.mendeley.com/datasets/89c9r5m2gx/1).

Лицензия: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

Использован архив `Bean Leaf Disease Original Image.zip`. Это отдельный набор из Бангладеш, не исходный Beans из Makerere. Из каждого класса выбрано шесть фотографий: имена файлов отсортированы, затем взяты шесть равномерно расположенных позиций, включая первую и последнюю. Отбор сделан до запуска модели.

Исходные метки: `Angular Leaf Spot` — пятнистость, `Rust` — ржавчина, `Fresh Leaf` — здоровый лист. Сохранены метки авторов; самостоятельная диагностика заболеваний не проводилась.

Фотографии уменьшены с сохранением пропорций до размера не более 512×512 и сохранены как JPEG. Фон не обрезался. При распознавании применяется обычное изменение размера до 96×96.

В `sources.csv` для каждой фотографии записаны путь внутри исходного архива, ссылка на архив, исходные размеры и SHA-256 оригинала. Из большого ZIP частичными запросами скачаны только выбранные файлы.

Этот набор используется только для проверки сохранённой модели и не включался в обучение, валидацию или подбор настроек.
